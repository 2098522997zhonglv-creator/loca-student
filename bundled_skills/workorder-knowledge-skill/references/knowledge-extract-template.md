# 需求知识沉淀模板

完成需求分析定稿后，将可复用业务规则写入：

1. 本地：`{产品线}/{需求名}/requirements/{需求名}-知识沉淀.md`
2. loca 知识库文档标题：`{产品线}/{需求名}/知识沉淀`

Callie 线可兼容 `{需求名}-Callie知识沉淀` 标题。

## 合并规则

- 只沉淀可确认事实；推测放入待确认项。
- 同一需求重复分析时更新原条目并注明修订日期，不重复堆积。
- 跨需求通用规则提升到 `{产品线}/全局规则/...`。
- 与历史规则冲突时保留双方来源并标注待确认，不直接覆盖。
